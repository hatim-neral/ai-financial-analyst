# 5-minute demo walkthrough

The recorded walkthrough is built by `demo/walkthrough/` from the running app (see `demo/README.md`). This is its
script, generated from `demo/walkthrough/script.py`, so the doc and the video always match. Total: 4:40.

To record it yourself instead: open the app, follow the **Show** column, and read the **Say** column. To re-voice
the generated video, read the same lines over it; each one is timed to its scene.

Before recording: open the live app a few minutes early (free apps sleep when idle); use a browser at a readable zoom.
If the AI is rate limited, wait a minute: the app rotates providers and the dashboard keeps working.

| 3:12–4:00 | Architecture card: loader → metrics → agent ⇄ model → guard → verified answer | Under the hood, there are four layers. The loader validates the file. The metrics module does every calculation and records its evidence. The agent lets the model call tools, and the guard checks the draft before anything is shown. A figure passes only if it's a correct rounding of a calculated value: six point nine eight lakh passes for six lakh ninety seven thousand, but thirty percent fails for twenty eight point seven six. Only calculated results go to the model. Raw rows and descriptions never leave the app, and API keys live in secrets, never in the code. It runs entirely on free model tiers: two models on Groq first, then Gemini, and any other free provider you add. When one hits its limit, the next takes over automatically.
